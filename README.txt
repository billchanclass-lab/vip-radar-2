VIP 經營雷達 2.0｜投顧報告中心原型

快速預覽：解壓縮後，直接開啟根目錄的 index.html。index.html 旁邊必須保留 reports 資料夾，PDF 下載連結才能正常工作。
GitHub Pages：將 index.html、README.txt 及 reports/ 一起上傳至同一個 repository 根目錄，再啟用 Pages。

此為靜態原型，客戶與持倉均為示範資料。報告配對在瀏覽器端依股票代碼完成，不會上傳顧客資料。

授權提醒：隨附研究報告含著作權與散布限制。僅供內部原型檢視；公開 repository、GitHub Pages 或傳送顧客前，請先取得公司書面授權並確認核准流程。
